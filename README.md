# PhonePilot AI

تطبيق ذكي لتسجيل المهام على الشاشة، تعلم أنماطها، وتنفيذها تلقائيًا عبر خدمة الوصولية في Android.

## الهيكل
- ROADMAP.md: خطة الطريق على أربع مراحل
- ARCHITECTURE.md: التصميم المعماري للوحدات
- DATABASE_DESIGN.md: تصميم جداول غرفة قاعدة البيانات
- SECURITY.md: سياسات الأمان والتخزين
- TESTING_STRATEGY.md: استراتيجية الاختبار
- AI_INTEGRATION.md: تكامل نموذج AI عبر HTTP
- android-app/: مشروع Android Kotlin + Compose + Room
